## What is not covered

- Packing at 2 and 4 bytes is L3's only: no cell passes 255 at L2's bounds (m <= 6), so L2's packed rows at 2 and 4 bytes are 0; L3's packing properties reach both widths.
- CUDA under compute-sanitizer: not run. dev's ASan and UBSan cover the host code only.
- The hybrid's work limit: L2 checks R11's stop eids on the CPU and on cuda, not on the hybrid (about 170 ms a graph alone).
- sg_ord's count len_I has no single L1 theorem: order_test decides each intermediate, Scan's lemmas say the scan visits each once, and L2 checks the count.
- The DFS over node sequences (simple paths, U and V excluded) is L2's and L3's, not L1's.
- Machine width is L3's (timestamps at the int32 limits, windows to INT32_MAX), not L1's: L1's integers are unbounded.
- Reachability pruning is legacy only: proved for Q5's strict order, planned only for legacy tcyc; clean tcyc never prunes.
- ReachScratch::search meets Search only up to L2's bound (walks of at most 5 edges); the 9-round end is L3's k_max property.
- Batch position: batched L2 runs put only a batch's first and last member at node 0 and the arrays' ends; the runs with each graph alone (dev, the limit-1 checks) cover position at smaller bounds.
- CUDA's heavy-kernel clamp at UINT32_MAX, fused slots at 4 bytes, the 4 MiB pack staging chunks: L3 and test_pack_fuse at most, not L2.
- CPU races: L2 runs 12 threads over batches, L3 two threads per case; no thread sanitizer.
